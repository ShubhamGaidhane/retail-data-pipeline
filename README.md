# Retail Data Pipeline

A hands-on data engineering project for learning CI/CD with GitHub Actions and Databricks.

## Business objective

Produce daily sales summaries from orders, customers, and products.

## Data layers

- Bronze: retain raw input data.
- Silver: clean records, remove duplicates, and validate data.
- Gold: calculate daily sales metrics.

## Planned tools

- Python, SQL, and PySpark for data processing.
- Databricks for running pipelines and storing tables.
- GitHub for version control and code review.
- GitHub Actions for automated testing and deployment.

## Development workflow

Create a branch, make changes, open a pull request, pass automated checks, review, and merge into main.
